Working papers and experiments. Archived on Zenodo as the *Universal Language Learning series*
(CC-BY-4.0); the concept DOI [10.5281/zenodo.21971310](https://doi.org/10.5281/zenodo.21971310)
always resolves to the latest version. Citation metadata in [CITATION.cff](CITATION.cff).

- [`universal-language-learning/`](universal-language-learning/) — the language-learning trilogy
  (*On Learning Languages*, *Perfect Theory*, *Universal Language Learning Machine*) with lab notes
  and the sealed-prediction order-dependence experiments (`euh_pkg`, `ner_enrich_pkg`).
- [`two-board-problem/`](two-board-problem/) — the Two-Board problem: a formal MDP of the
  mathematical-discovery task. Archived: DOI
  [10.5281/zenodo.18498107](https://doi.org/10.5281/zenodo.18498107).
- [`oracles-axioms-paper/`](oracles-axioms-paper/) — axiomatic extensions of Turing machines as oracles.
- `critical-volatility-and-v*/` — critical volatility threshold for the log-normal to power-law
  transition. Preprint: [arXiv:2601.01269](https://arxiv.org/abs/2601.01269).
- [`paper-tools/`](paper-tools/) — the shared markdown build pipeline (HTML / PDF / arXiv) for every
  paper here; CI rebuilds all papers on each push and attaches them as artifacts.
